# v0.2 授权网络组件

页面顶部与主按钮均提供“启用连接后台”。点击后先显示文件位置、运行权限与移除说明，勾选确认再点击“授权安装”。管理员密码仅输入 macOS 系统窗口。

安装的文件为：

- `/Library/PrivilegedHelperTools/net.nebula.gui/nebula-gui-helper`
- `/Library/LaunchDaemons/net.nebula.gui.helper.plist`

组件由 launchd 管理，开机启动但不自动连接。GUI 与配置后台保持普通用户身份，组件只接受指定用户的连接、断开、状态与健康请求。配置必须内嵌凭据并重新校验，不能传入文件路径或任意命令。控制会话消失时清理其隧道。

## 安装事务

用户批准后，固定目的安装脚本检查受保护目录、旧 Nebula 服务状态与独占安装锁；复制组件到 root 管理的临时文件，验证 SHA-256 与本地代码签名后发布。注册后降到被授权用户执行健康检查，确认就绪才提交；失败时回滚本次发布的服务与文件。已有安装不会被静默覆盖，需先移除。

安装采用管理员明确批准的传统 LaunchDaemon。此路径与先前讨论的 SMAppService 不同；仍是本机开发构建，不代表完成 Developer ID、公证或正式分发验证。

## 移除

连接断开后点击“管理后台”，确认“授权移除”。安装不完整时也可从授权确认页选择“移除已有组件”。只移除 Nebula GUI 的组件，不删除原始配置、GUI 保存的网络或旧部署的启动项。受保护的空目录可能保留。

授权窗口等待或安装执行期间，App 拒绝提前退出，需先完成或在系统窗口取消。取消授权不自动连接网络。
