# Nebula 原生界面改版（Issue #20）

用户于 2026-11-05 选择整体优化：网络侧栏、概览／节点／配置分页、常驻连接操作区、菜单栏面板和原创图标。产品仍面向拿到配置文件后访问其他 Nebula 节点的普通 Mac 用户。

## 1. 方向与本机依据

视觉方向：克制的原生网络工具，系统字体、浅灰层次和青绿色强调色。首页让用户先知道所选网络和连接状态，再执行主要操作，最后查看详情。

本机查看 `/Applications/Vitals.app` 的 1.9.7（535）：概览用短标题、大数字、同组图标和浅灰圆角分区；顶部导航强调所选项；App 图标以高对比单一图形获得小尺寸辨识度。其中文资源还说明了菜单栏快速查看与完整窗口的分工。实际截图仅留本机，未将机器读数、进程名或真实 Nebula 截图加入仓库。没有完成 Vitals 各个标签和菜单栏面板的逐项交互验收，不据此宣称其内部实现。

取三项具体属性：胶囊形选中导航、通过背景色阶分层的浅色表面、少量语义强调色。Nebula 保留青绿色和网状连接标识，原创绘制节点图形，不拷贝 Vitals 的蓝色脉冲图标、资产或源码。

方案比较：最小版只整理现有长页与图标，约一轮小改、回归风险低，但滚动时仍难找到断开；推荐版复用 AppModel 分成三个任务页面，约一轮完整 UI 实现与验证、风险集中在操作入口迁移；菜单栏优先版需重整窗口行为与偏好设置，工作量和生命周期回归风险更高。用户已选择推荐版。

## 2. 颜色与角色

| 角色 | 值／来源 | 用途 |
| --- | --- | --- |
| 强调 | 浅色 #147A61，深色 #5BCCAA | 连接、选择和复制反馈 |
| 画布 | 浅色白／深色 9% 灰 | 主工作区 |
| 表面 | 浅色 94% 灰／深色 15% 灰 | 有意义的摘要分区 |
| 主／次文字 | 系统 primary／secondary | 跟随明暗与辅助功能 |
| 警示 | 系统 orange | 授权异常、证书临期、未确认 |
| 破坏性 | 系统 red | 断开、取消恢复、移除 |

颜色仅辅助识别，状态同时提供文字和图形。普通状态不使用橙色。系统颜色继续支持对比度和明暗外观，不加入网页 CSS／字体依赖。

## 3. 字体

使用 Apple 系统 UI 字体，让中文、菜单栏和平台控件协调。正文 13，次要说明 12，网络标题 20／semibold，本机 IP 26／monospaced；记录数量使用等宽数字，证书指纹可选择并换行。避免把小字号说明当作主要操作依据。

## 4. 组件与交互

圆角命名尺度：small 8、medium 12、large 20；页面导航为左侧栏纵向列表，选中项使用 medium 圆角与强调色背景。可操作目标至少 40 点，标准按钮使用同一圆角样式；菜单栏原生菜单项沿用平台尺寸。

连接用填充强调按钮；断开用红色文字、停止图标和轻量边框。忙碌显示进度并阻止重复提交，连接中保留独立的取消并断开入口。后台健康异常不能遮住现有断开入口。所选网络与活动网络不同时，显示活动网络名称并提供断开活动连接入口。

签名微交互是地址复制后原位置的短暂勾选／“已复制”反馈；120ms 淡入淡出，不改变控件尺寸。按钮按压缩至 0.97；开启减少动态效果时关闭缩放与过渡。页面切换只切换视图，不触发连接；页面与错误区保留稳定占位，避免操作按钮跳动。

## 5. 布局与信息结构

左侧栏固定约 200 点，自上而下为概览／节点／配置／日志页面导航（未选择网络时隐藏）、独立滚动的网络列表与当前连接标志、导入入口和版本。右侧顶部在滚动区之外，包含网络标题、连接状态和主操作。

概览：地址与复制 → 证书摘要 → 自动恢复 → 最近连接事件。节点：延迟汇总 → 记录含义说明 → 搜索／筛选 → 节点行（最新延迟、迷你曲线，展开查看详细曲线与统计）与地址复制。配置：身份／有效期／指纹 → 通知 → 后台管理 → 更新／回滚／移除 → 诊断。

后台正常时在概览简短展示；缺失、待升级或健康不确定时在顶部显示对应提示，可在配置页进入既有授权审阅。授权步骤仍使用原有系统确认与后台实现。

菜单栏：品牌和整体状态 → 活动网络（否则所选网络）与地址复制 → 连接／断开 → 打开完整窗口、导入及退出。没有配置时显示导入入口，不提供无目标的连接按钮。

数据流保持无环：

```text
MainView / MenuContent ──观察──> AppModel ──既有操作──> AppBackend
          │                        │
          └──页面、复制反馈等局部状态┘
```

## 6. 层次与图标

使用原生背景色阶和细分隔线，避免每块说明都套卡片；连接摘要和证书摘要可单独成组。侧栏、主区和摘要表面可辨认；深色按系统动态颜色显示。

原创节点标识由三个末端与中心连接点组成；App 图标使用深浅青绿底上的白色高对比图形，菜单栏使用同一几何图形的模板图像。App 图标由仓库内绘制源码本地生成 iconset／icns，在签名前复制到资源目录并写入 CFBundleIconFile。构建不依赖图像生成服务、网络或 Vitals 资产。

## 7. 护栏与恢复

- 隧道已启动不等于所有节点在线；只展示已有记录、证书和实测探测数据。
- 活动网络与选中网络分别判断，切换页面或选中网络都不自动连接。
- 后台错误不删除现有状态，取消与断开仍走既有生命周期路径。
- 不改变配置格式、目录、证书、root 组件或协议；回退提交可恢复旧界面，无需数据迁移。
- 不覆盖或退出用户当前运行的 App；视觉验证使用独立预览和合成身份。
- 不引入账号、API Key、字体下载或第三方运行时。GitHub CLI 已验证可访问。

四角度检查：离线仍可查看原生界面，操作失败沿用现有错误；节点增加十倍仍使用搜索与 50 条增量显示；撤回 UI 无持久化数据变更；Vitals 细节无法完整复现时，采用原生控件和本机已观察到的层级原则，不依赖其内部实现。

## 8. 尺寸与验收

支持现有最低 macOS 13，最小宽度 760 点；验证 760、900、1280 点宽，长网络名、长指纹、多地址和空列表。窄窗口不增加横向操作冲突；菜单栏面板约 320 点，内容独立布局。同步查看浅色、深色和减少动态效果，键盘导航与图标可访问性标签。

复用现有 Go race、Swift 模型和 AppKit 退出回归。新增必要的状态投影与导航副作用回归；复制反馈通过真实控件检查。通过独立、没有网络服务的原生预览覆盖空、断开、已连接、处理中、其他网络活动、授权异常、错误及恢复状态；合成数据显式标识。现有真实连接只读观察，不执行系统中断验收。

实际涉及 19 个文件（视图拆分及独立预览／CI 增加文件数），包含设计文档、SwiftUI 视图／共享组件／状态展示、图标源码与构建、开发预览与必要测试；没有新服务。实际范围以 PR diff 为准。完成后执行 check 审查，适用测试与远端 CI 通过后按常设授权合并。

## 9. 后续实现提示

- 新按钮复用 NetworkActionButton：固定最小高度 40，连接强调色、断开 red，不自行推导后台权限。
- 新状态行复用 ConnectionPresentation：明确当前网络与活动网络，给出文字与图标，不只有色点。
- 新摘要使用 12 点圆角、16 点内边距、13 点正文，背景用动态 surface；页面间距 20。
- 新图标按钮复用 CopyAddressButton 或原生工具按钮，具备名称、帮助和 40 点命中区域。
- 所有预览是开发工具中的合成数据，不进入正常启动路径，不自动导入或连接。
