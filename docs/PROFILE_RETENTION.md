# 配置副本保留与清理

Issue #6。现有文件存储格式保持不变，没有接入 Keychain 或迁移真实凭据。

每个非活动配置保留当前版本和一个回滚版本。活动配置在确认断开前整目录跳过，即使隧道状态失败或清理未确认也继续保护。列表刷新、成功导入、确认断开和恢复清理后会尝试回收无引用的旧版本；重命名不消耗回滚版本。

清理失败不会把成功导入改报失败：记录 profile_cleanup_pending 事件，后续列表刷新重试。当前或回滚索引／文件不可读取时，该配置不清理。没有索引、也没有移除标记的旧目录保留供恢复，不猜测其已无用。

## 删除与中断恢复

移除先将索引改名为 .removed 标记，再清理受管版本。进程中断或删除失败时，标记供下次刷新重试；当前列表不再展示已逻辑移除的配置。GUI 对 profile_cleanup_pending 仍刷新列表，并保留尚未确认文件清理的提示。最后标记移除失败也返回相同语义。

每个版本先检查整个目录，只接受私有普通文件 config.yaml、profile.json 和已识别的索引临时文件。删除使用已打开私有目录的 fd，相对 unlink，不递归；拒绝符号链接、硬链接、嵌套目录、未知文件和权限不安全的目录。无法确认归属时保留数据并记录待重试。用户导入源文件保持不变。

本次验证覆盖进程中断恢复，不宣称已证明断电或内核崩溃下的持久性；现有索引重命名没有完整父目录同步与断电故障验证。文件逻辑删除也不保证 SSD 物理擦除、备份或快照中的旧副本消失。

## 验证

10 个新增 Go 测试（含 5 个链接／未知内容子场景）覆盖多次更新、回滚和重开；活动及未确认清理保护；损坏索引；不安全旧目录；移除中断重试；权限失败后重试；无索引目录保留；成功导入但清理失败；已提交移除的重试语义。全部通过 Go race。

独立产物目录执行 scripts/test.sh，通过完整 Go race、27 个 Swift 客户端测试与 4 个 AppKit 退出场景；Go vet 和 diff 检查通过。安全与架构审查发现的界面刷新和错误语义已修正。未替换当前 App、未在用户真实存储执行清理、未升级 root 组件。
