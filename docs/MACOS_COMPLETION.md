# macOS 首版补全

范围已于 2026-11-04 确认：会话恢复与睡眠唤醒、节点连通诊断、证书到期通知、组件升级。iOS/Linux、Keychain 迁移与正式签名分发仍为独立阶段；本批不增加账号、云 API 或系统服务。

## 方案选择

| 方案 | 工作量与风险 | 取舍 |
| --- | --- | --- |
| 最小：只同步状态、手动重连 | 小；行为最保守 | 不能覆盖普通用户的唤醒恢复需求 |
| 本次会话内有限恢复 | 中；需要证明旧连接已清理 | 采用，复用现有进程管道与单控制会话 |
| 重启后持久自动连接 | 登录后自动连接已由 #63 以可选开关实现；登录前连接仍需独立后台与会话策略 | 登录前连接不纳入 |

恢复只记住本次用户连接意图。主动断开、退出或选择另一配置使旧恢复任务失效。失败最多重试五次，按 1/2/4/8/16 秒退避；持续稳定一分钟才重置重试预算。睡眠或系统无可用网络时暂停。未确认清理时，由认证组件确认旧控制会话已完成清理，再允许重新连接。

唤醒后先查询状态；有效隧道请求内核重新绑定 UDP，不以重建隧道作为默认动作。该 API 只证明请求执行，不宣称对端可达；可达性由单独 ICMP 探测报告。旧组件通过版本元数据识别并提示升级，不向不支持的新接口发送控制请求。

```text
系统睡眠／网络事件 → GUI 会话意图与退避 → 普通配置后台
                                           │ 认证本机协议
                                           ▼
                                      单一 root 组件 → 固定 Go 内核
节点诊断 → 普通用户 ICMP socket       证书提醒 → 用户主动启用的系统通知
```

节点探测仅允许当前连接证书网段内的单播目标，拒绝本机地址；三次带随机匹配数据的 ICMP Echo，限时、限速，不解析 ping 命令文本。诊断导出继续排除地址及原始凭据。

通知默认关闭，用户主动请求 macOS 许可。按 30/7/1 天及过期状态计划提醒；配置更新或删除后取消旧提醒；同一证书版本不重复提醒。通知不包含设备名、地址或证书正文。没有权限时保留 App 内到期提示。

升级固定安装位置的组件，先备份受保护文件，停止旧服务，发布新文件，验证版本与健康后提交；失败恢复旧文件和服务。只有用户在 GUI 明确确认并完成系统管理员授权才执行。开发测试只运行隔离事务替身，不改变本机安装。

## 验证与回退

测试覆盖取消与迟到响应、有限退避、稳定重置、睡眠暂停、无网络、清理未确认、旧组件兼容、探测超时／伪造回复／地址边界、通知阈值与版本替换、升级成功与失败回滚。现有 Go race、Swift 测试与真实 AppKit 退出回归继续执行。

失败时保持可查看配置、手动断开与导出诊断；不依赖外部服务。节点数增长时探测仍为单目标，通知最多保留最近的 60 项。GUI 与普通后台改动可通过切回原 App 回退；升级失败则恢复原受保护组件，不迁移配置数据。当前运行 App 与已安装组件不由开发命令替换。
